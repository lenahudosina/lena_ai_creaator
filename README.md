# Лена Худошина — лендинг

Адаптивный лендинг (десктоп + мобильная версия) для AI-креатора коммерческого визуала.
Чистый HTML + CSS, без сборки — можно сразу заливать на GitHub Pages.

## Структура
```
index.html      # разметка
styles.css      # стили (адаптив через @media)
images/         # изображения-плейсхолдеры
```

## Картинки
В папке `images/` лежат серые плейсхолдеры с правильными пропорциями.
Заменяй их своими экспортами из Figma, **сохраняя имена файлов**:

| Файл | Где на странице |
|------|-----------------|
| `hero-main.jpg` | главное фото в hero |
| `hero-source.jpg` | маленький «исходник» |
| `work-catalog.jpg` | Базовый AI-Каталог |
| `work-lookbook.jpg` | Стилизованный Лукбук |
| `work-campaign.jpg` | Имиджевый Кампейн |
| `work-product.jpg` | Продуктовая съёмка |
| `work-model.jpg` | AI-модель бренда |
| `work-video.jpg` | AI-Видео |
| `work-social.jpg` | AI-контент для соц. сетей |
| `work-ugc.jpg` | UGC |
| `about-portrait.jpg` | портрет в блоке «Почему именно я» |

## Публикация на GitHub Pages
1. Создай репозиторий и залей файлы.
2. Settings → Pages → Source: `main` / `root`.
3. Готово — сайт по адресу `https://<username>.github.io/<repo>/`.
